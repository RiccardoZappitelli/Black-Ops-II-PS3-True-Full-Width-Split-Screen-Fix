# Black Ops II PS3 — Full-Width Split-Screen Fix

**Finally, no more black vertical bars in two-player split-screen!**

This modification allows Call of Duty: Black Ops II on PlayStation 3 to use the entire screen width during horizontal split-screen, instead of restricting both players to a narrower area.

### Compatibility
- **Game:** Call of Duty: Black Ops II
- **Region:** BLES01718
- **Update:** 1.19
- **Console:** PS3 with HEN (tested)
- **Modes:** Multiplayer and Zombies (both tested)

### Installation

1. Enable HEN on your PS3.
2. Navigate to `/dev_hdd0/game/BLES01718/USRDIR/`.
3. Back up the original `t6mp_ps3f.self`.
4. Rename the downloaded `mp_fullwidth_hen.self` to `t6mp_ps3f.self`.
5. Copy it into the folder, replacing the original.
6. Launch Black Ops II from your disc and enjoy full-width split-screen!

### Important
- Tested on the BLES01718 disc version with update 1.19.
- Other game regions and versions have not been tested.
- Use offline/local split-screen only.
- Keep a backup of the original executable.
